# Test Results

## What Works
- Majority of quotes match -- 17 of 25
- Importing Artist information, contact information, and creating artist_contact records worked
- All quotes set to Draft status


## What Doesn't Work
- False negatives on the validation script. Claude thought there were only 4 exact matches, but this was inaccurate. This leads me to believe that our validation script is not calculating the "Quote Total" in StarTracker data correctly. My gut says we're not combining the `TourBudget` columns when multiple rows in the StarTracker export CSV share a TourID. Recall: Each row on the Quotes CSV represents a vehicle, and by joining on TourID we'll calculate a total for the entire tour, which is equivalent to the QUOTE in Bravo. Priority high: by having an accurate validation script, we can run these exports, quickly assess where there are financial mismatches, and focus on reviewing those that don't match. 
- Notes don't import. The `Notes` field in StarTracker data needs to import `entity_note` records in Bravo, whcih need to be associated to the quote on which they should belong according to the `TourID` <> `quote.id` mapping.
- Missing "Co-Driver Rate, Daily" Line Item. See below
- Missing Co-Driver Per Diems line item. See below.

⚠︎ There are a few  'edge cases' here where StarTracker data appears in unexpected ways. I wouldn't expect the Bravo import to know how to correct these, so they did not "fail" per se -- but had the validation script worked correctly, I would be able to quickly identify that these had issues and seek manual resolution.
